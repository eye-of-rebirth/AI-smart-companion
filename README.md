
# 🤖 AI 智能伴侣

基于 Streamlit 和 DeepSeek 大语言模型构建的智能聊天助手，提供流畅的对话体验。


## ✨ 功能特性

- 🎯 **智能对话** - 基于 DeepSeek 大语言模型，支持多轮对话
- 💬 **流式输出** - 实时逐字显示 AI 回复，体验流畅
- 🎨 **美观界面** - 使用 Streamlit 构建现代化聊天界面
- 🔒 **安全配置** - 环境变量管理 API 密钥，保障安全
- 📝 **历史记录** - 自动保存对话上下文，支持连续交流

## 🛠️ 技术栈

- **前端框架**: [Streamlit](https://streamlit.io/) - 快速构建数据应用的 Web 框架
- **AI 服务**: [DeepSeek API](https://platform.deepseek.com/) - 深度求索大语言模型
- **SDK**: OpenAI Python SDK - 统一的 API 调用接口
- **环境管理**: python-dotenv - 环境变量加载
- **包管理**: [uv](https://github.com/astral-sh/uv) - 超快的 Python 包管理器
- **Python**: >= 3.12
